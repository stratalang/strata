# Installation

> **Early Access Required**: Strata is currently in **very early development**: it's not even in alpha yet. Access is limited and requires approval.

## Requirements

Strata is designed to be self-contained:

- **OS**: macOS or Linux
- **PHP**: Optional. Strata targets an [internal PHP 8.4 runtime](/language/advanced/php-runtime) if no system PHP is found.

> [!INFO]
> Support for Windows is planned. You should consider using [WSL](https://learn.microsoft.com/en-us/windows/wsl/) for now.

## Requesting Access

To use Strata, please submit a request here: [Request Access](https://app.formbricks.com/s/cmjydyb0s6045ad019rtamvv9)

Once approved, you'll receive instructions on how to access and install Strata.
